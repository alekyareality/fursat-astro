# Equirectangular 360° Panoramas

Drop 360° equirectangular panoramas (2:1 aspect ratio, e.g. 4096×2048 or 2048×1024, `.webp` or `.jpg`) into this directory.

### Example filenames:
- `fursat-main-360.webp`
- `lounge-360.webp`
- `bar-360.webp`

When one or more equirectangular images exist in this folder, `PanoramicViewer.astro` automatically exposes the **"360° View"** toggle button, projecting the panorama onto an interactive inside-facing sphere with draggable look-around and spatial hotspots.
